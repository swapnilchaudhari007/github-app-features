# Code of Conduct

## Our pledge

We want **github-app-features** to be a welcoming, harassment-free space for everyone, whatever their experience level, background, identity or the tools they use to write code, AI included.

## Expected behavior

- Be kind, patient and constructive in issues, reviews and discussions
- Give feedback on the work, not the person
- Assume good intent, and ask before you judge
- Credit others' ideas and code
- Help newcomers find their first contribution

## Unacceptable behavior

- Harassment, insults, trolling or personal attacks
- Discriminatory jokes or language
- Publishing others' private information without permission
- Spamming issues or PRs, including bulk low-effort AI-generated content
- Any conduct that would be inappropriate in a professional setting

## AI-assisted contributions

This project is about AI-powered tooling, so AI-assisted work is welcome, with a few ground rules:

- **You own what you submit.** Review, test and understand every line before opening a PR.
- **Be transparent.** Mention in the PR description if AI tools helped write significant parts of it.
- **No unverified claims.** Don't paste AI output that hasn't been checked for accuracy, licensing or security.
- **Respect reviewers' time.** Keep PRs focused, and don't flood the repo with generated changes.

## Enforcement

Report unacceptable behavior to the maintainer, [@swapnilchaudhari007](https://github.com/swapnilchaudhari007). All reports are reviewed promptly and kept confidential.

Depending on severity, the maintainer may:

1. **Correct:** a private note explaining the issue
2. **Warn:** a formal warning with consequences for repeated behavior
3. **Temporary ban:** a time-limited block from interacting with the project
4. **Permanent ban:** removal from the project community
