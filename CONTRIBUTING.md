# Contributing to github-app-features

Thanks for your interest in contributing! This project showcases AI-powered GitHub app features and capabilities, and contributions of all sizes are welcome.

## Ways to contribute

- Report bugs or suggest new features via [Issues](https://github.com/swapnilchaudhari007/github-app-features/issues)
- Improve documentation and examples
- Add or enhance feature showcases
- Review open pull requests

## Getting started

1. Fork the repository and clone your fork:
   ```bash
   git clone https://github.com/<your-username>/github-app-features.git
   cd github-app-features
   ```
2. Create a branch for your change:
   ```bash
   git checkout -b feature/short-description
   ```
3. Make your changes and commit with a clear message:
   ```bash
   git commit -m "feat: add short description of change"
   ```
4. Push to your fork and open a pull request against `main`.

## Commit message convention

Use [Conventional Commits](https://www.conventionalcommits.org/) where possible:

- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation only
- `refactor:` code change without behavior change
- `chore:` tooling, config, or maintenance

## Pull request guidelines

- Keep PRs focused on a single change
- Describe what the change does and why
- Link related issues (e.g. `Closes #12`)
- Update the README or docs if behavior changes
- Make sure everything builds and runs before requesting review

## Reporting issues

When opening an issue, please include:

- A clear title and description
- Steps to reproduce (for bugs)
- Expected vs. actual behavior
- Screenshots or logs if helpful

## Code of conduct

Be respectful and constructive. Harassment or abusive behavior will not be tolerated.
